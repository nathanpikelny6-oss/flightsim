# Aircraft models

Logo-free exterior meshes by [amvlab](https://github.com/amvlab/aircraft-models),
licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Included files:

- `A320_nologo.glb`
- `A350_nologo.glb`
- `A380_nologo.glb`
- `B737_nologo.glb`
- `B787_nologo.glb`

No changes were made to the mesh data. The sim scales each file to published
aircraft length and flies it on the globe. These are not Boeing or Airbus
products, and those names are used only to identify the aircraft type.
